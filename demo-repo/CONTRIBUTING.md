# Contribuer à taskman

Merci de votre intérêt pour le projet.

## Avant de proposer une modification

1. Lancez les tests avec `python -m pytest` : ils doivent tous passer.
2. Ajoutez un test pour chaque correction de bug.
3. Gardez le projet sans dépendance externe.

## Style

- Fonctions courtes, avec une docstring d'une ligne.
- Noms en anglais, documentation en français.
- Pas de `print` dans le code du paquet.

## Messages de commit

Une ligne à l'impératif, par exemple : `Corrige le calcul du taux de complétion`.
