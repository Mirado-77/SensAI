# X3 Export et partage

## Story 1

En tant que développeur qui a corrigé un bug avec l'agent, je veux exporter la session en JSON,
Markdown ou PDF, afin de l'archiver ou de la joindre à une issue ou à une pull request.

Critères d'acceptation :
- `sensai export <session> --format json|md|pdf` exporte la conversation (messages de
  l'utilisateur et de SENSAI, sans les sorties brutes d'outils) et le document d'état (M4).
  Un préfixe de l'id suffit.
- Sans `-o`, le JSON et le Markdown s'affichent sur la sortie standard ; avec `-o <fichier>`, le
  fichier est écrit. Le PDF exige `-o`, sinon la commande s'arrête avec le code 2.
- Un message interrompu est marqué `(interrupted)`. Un document vide n'ajoute pas de partie
  « State document ».
- Une session inconnue ou ambiguë s'arrête avec le code 2 et un message d'erreur. Sans
  WeasyPrint, l'export PDF donne un message qui dit comment l'installer.

## Story 2

En tant que développeur, je veux partager une session avec un lien qui s'ouvre dans un navigateur
sans compte, afin de la montrer à un collègue qui n'a pas SENSAI.

Critères d'acceptation :
- `sensai share <session>` enregistre une page HTML sous un token aléatoire d'environ 128 bits et
  affiche `http://<host>:<port>/s/<token>`. Le lien est une photo de la session à ce moment.
- `sensai share --serve` sert ces pages en lecture seule : 200 pour `/s/<token>`, 404 pour un
  token inconnu, pour tout autre chemin et pour une tentative de sortir du dossier (`..`).
- Le contenu de la page est échappé : un message qui contient du HTML ou un `<script>` s'affiche
  comme du texte.
- Les secrets du fichier `[guards] env_file` et les formats de clés connus sont masqués dans
  l'export comme dans le partage (EV2).
- `sensai share --revoke <token>` supprime la page : le lien renvoie 404. Un token inconnu ou
  invalide ne supprime rien et donne le code 2.

## Tests

Les tests portent l'ID de la fonctionnalité avec `@pytest.mark.feature("X3")`.

- `tests/unit/test_export.py` : contenu de l'export, masquage des secrets, Markdown, HTML échappé,
  PDF (ignoré sans WeasyPrint) et erreur sans WeasyPrint, token, révocation, serveur HTTP (200 et
  404), configuration par défaut, commandes `sensai export` et `sensai share`.
