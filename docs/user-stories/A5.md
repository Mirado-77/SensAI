# A5 Personas

## Story 1

En tant que développeuse qui vient de faire corriger un bug par SENSAI, je veux passer à une
persona « reviewer » dans la même conversation, afin qu'elle relise la correction en voyant tout
ce qui a été fait, sans pouvoir modifier le code par erreur.

Critères d'acceptation :
- `/persona reviewer` change la persona pour les tours suivants et affiche
  `Persona: reviewer [read]: ...` ; la session et son historique sont gardés, le tour suivant
  envoie au modèle tous les messages précédents.
- Le prompt de la persona est envoyé après le prompt de base (A4) et avant le profil (M1).
- La persona `reviewer` n'a que les outils de risque `read` : `write_file`, `edit_file` et
  `run_command` ne sont plus proposés au modèle, et `/tools` ne les liste plus.
- Si le modèle appelle quand même un outil interdit, l'appel est refusé sans être exécuté :
  événement `tool.failed` avec `not allowed`, et le modèle reçoit le refus.
- `/persona dev` redonne tous les outils, toujours dans la même session.

## Story 2

En tant que membre de l'équipe qui prépare la démo, je veux définir les personas en
configuration et choisir celle du démarrage, afin d'en ajouter ou d'en régler une sans toucher
au code.

Critères d'acceptation :
- Une persona est un fichier `configs/personas/<nom>.toml` avec `description`, `prompt` et
  `risks` (parmi `read`, `write`, `exec` ; toutes par défaut) ; `dev` et `reviewer` sont fournies.
- `[prompts] persona` choisit la persona du démarrage (`dev` par défaut, `""` pour aucune) ;
  `sensai chat --persona reviewer` la remplace pour un chat. La bannière affiche la persona active.
- `/persona` seul liste les personas avec leurs outils et marque l'active d'un `*`.
- Une persona inconnue est refusée avec la liste des personas connues : le chat ne démarre pas
  (code 2), ou garde la persona active si c'est `/persona`. Un fichier invalide (clé inconnue,
  prompt vide, risque inconnu, TOML cassé) est refusé avec un message clair.
- Chaque tour enregistre la persona dans l'événement `run.started` du journal.
