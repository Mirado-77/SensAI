# A3 Diff avant écriture

## Story 1

En tant que développeuse qui laisse l'agent modifier ses fichiers, je veux voir le diff exact de
chaque modification avant qu'elle soit écrite, afin de refuser un changement que je ne veux pas.

Critères d'acceptation :
- Avant tout `write_file` ou `edit_file`, la CLI affiche un diff unifié (`--- a/<chemin>`,
  `+++ b/<chemin>`, `@@ ... @@`) puis demande `Allow? [y/N]`.
- Pour un fichier qui n'existe pas encore, le diff commence par `--- /dev/null`.
- Le fichier n'est pas modifié avant la réponse. Si l'utilisateur refuse, le fichier reste
  identique et le modèle reçoit « The user refused this action. ».
- Un contenu identique affiche `(aucun changement)`, un changement de fins de ligne seul affiche
  `(seules les fins de ligne changent)` et la création d'un fichier vide affiche
  `(création d'un fichier vide)`.
- Un diff plus long que `[files] max_diff_lines` (200 par défaut) est coupé et se termine par
  `... N lignes de plus`.
- Quand le diff est impossible (chemin hors des racines autorisées, texte à remplacer introuvable
  ou ambigu, fichier trop gros), l'aperçu est l'appel d'outil en JSON et l'outil renvoie son
  erreur au modèle.

## Story 2

En tant que développeur qui ajoute un outil à SENSAI, je veux que l'outil puisse fournir son
propre aperçu avant approbation, afin que l'utilisateur voie ce qui va se passer sans que le
runtime connaisse l'outil.

Critères d'acceptation :
- Un outil qui définit `async preview(args) -> str | None` voit ce texte dans la demande
  d'approbation et dans l'événement `approval.requested` du journal.
- Un outil sans `preview`, par exemple un outil MCP, garde l'aperçu `nom(args)` en JSON.
- Si `preview` renvoie `None` ou un texte vide, ou lève une exception, le tour continue avec
  l'aperçu par défaut.
- `preview` n'est appelé que si une approbation est nécessaire : jamais pour un outil autorisé
  sans demande, refusé par la politique ou appelé avec des arguments invalides.
- `preview` ne modifie jamais le fichier. L'annulation du tour pendant l'aperçu annule le tour.
